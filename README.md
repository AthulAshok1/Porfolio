# Athul Ashok - React Portfolio

A React + Vite conversion of my original HTML/CSS/JavaScript portfolio. The visual design is intentionally preserved while the implementation is organized into reusable React components and custom hooks.

## Tech Stack

- React
- Vite
- JavaScript (ES6+)
- HTML / JSX
- CSS

## Project Structure

```text
src/
├── components/
│   ├── Navbar.jsx
│   ├── ScrollProgress.jsx
│   ├── Hero.jsx
│   ├── About.jsx
│   ├── Education.jsx
│   ├── Skills.jsx
│   ├── Projects.jsx
│   ├── Experience.jsx
│   ├── Certifications.jsx
│   ├── Contact.jsx
│   ├── Footer.jsx
│   └── BackToTop.jsx
├── hooks/
│   ├── useScrollSpy.js
│   ├── useScrollReveal.js
│   └── useTypingEffect.js
├── App.jsx
├── App.css
├── index.css
└── main.jsx
```

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
